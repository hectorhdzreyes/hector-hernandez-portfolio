# Hector Hernandez Reyes — Digital Portfolio

Static HTML/CSS/JS portfolio for class (similar structure to a Google Sites student portfolio).

## Pages
- Home (`index.html`)
- About Me (`about.html`)
- Resume (`resume.html`)
- Job Skills (`skills.html`)
- Job Ad & Cover Letter (`job.html`)
- Company Profile (`company.html`)

## View locally
Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
